① 脏时间序列 —— 90 天，注入九种问题

NaN / null / 字符串 / 负数 / 重复时间戳 / 乱序输入 / 200 点恒定值（卡死的传感器）/ 一段全 0 / 一个 4800 的尖峰 / 两段空洞（2.5 天与 10 天）。 折线应当：剔除脏值并计数、按时间排序、合并重复时间戳、在空洞处断开、用分位域挡住尖峰。

② 退化输入 —— 每一种都曾经让图表消失过

全同值（域宽度为 0 → 除零）、单点、空数组、全脏值、1e15 与 1e-12 的极端量级。 任何一块变成空白或抛出异常，下面就会亮红。

③ 海量数据 —— 20 万点

200,000 个点，10 分钟分辨率、约 2.3 年。全部塞进 DOM 是不可能的，所以按时间桶降采样到可绘制的规模； 读数是降采样的耗时与倍数。

④ 类别爆炸 —— 50 个序列 vs 8 格调色板

分类色只有 8 个可用槽位。50 个序列必然重复颜色，这不是可以藏起来的问题 —— 正确的做法是告诉使用者，而不是假装颜色还有意义。

⑤ 恶意标签 —— 数据不可信

标签来自数据：400 字符、HTML 注入、引号与尖括号、emoji、RTL、控制字符、空白。 它们必须被转义，否则就是 XSS。

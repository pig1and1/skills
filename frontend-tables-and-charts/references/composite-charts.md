# 复合图表：细节

这是主文件 §10 的完整展开。**先读那节的"同量纲"硬前提，需要做法时再回这里。**

---

## 画法

**堆叠柱**：

- 从 0 **累积**着往上叠，每段用**累积值**算上下边界（不是各自的绝对值）
- **段的先后顺序在所有柱之间保持一致** —— 否则同一颜色在不同柱里代表不同层，图例就失效了
- **只有顶段做圆角**，底部直角 —— 这样一堆段看起来是**一根柱**，而不是一摞方块

**折线**：

- 数据点画在**每根柱的中心**，不是柱的边缘 —— 否则线与柱的对应看起来会偏一格
- 与柱共用同一条轴（前提是量纲相同）

**命中区**：

- 堆叠出来的段可能只有 1–2 像素高，鼠标根本点不中
- **给每根柱补一个覆盖整柱高度的透明命中矩形**，事件挂在它上面，而不是挂在可见的段上

## 点击与悬停的分工

见主文件 §8 与 §10。一句话版：**悬停给全部字段，点击只负责钉住。**

三处冲突要显式定规则：

- **钉住优先于悬停**：钉住后移开鼠标，面板内容不变
- **tooltip 跟不跟手要写明**：图外面板锁定钉住那条，跟手的 tooltip 显示当前悬停那条
  （"钉住的答案" vs "我正在指的东西"）
- **键盘必须能解除钉住**，否则按方向键面板不动，用户会以为键盘坏了

## 面积填充：它改变轴规则

**折线 + 面积填充 = 声明"这是数量"**，因此**必须从 0**。

代价真实：日常 1%、尖峰 5% 的比率，从 0 起画会被压成贴地直线。

**二选一**：要看清波动就**去掉填充**；要表达占比就**保留填充并接受压缩**。

## 窄窗口：直接标注要能退化成图例

窗口缩小时，线末端的直接标注会互相重叠或跑出画布。此时应**自动改为图表上方的色块图例**。

**这条必须在实现里显式处理**，不是"响应式会自己搞定"——它需要判断可用宽度、
切换两种标注渲染方式，是几行真实的代码。

实测参考：1180px 与 600px 是两套不同的约束；窄到某个宽度后，线末端标注已无容身之地。

> **本 skill 面向 PC 端网页**，所以交互只按"悬停读数 + 点击钉住"设计。
> 触屏（`hover: none`）需要的是另一套：点击即读数、标注退化、更大的命中区 ——
> 那不在本 skill 覆盖范围内，目标含移动端时要单独补。

## 派生序列（移动平均、累计值）要把参数说全

只说"画一条均值线"是不够的。以下每一项都会改变读者看到的东西：

| 参数 | 要决定什么 |
|---|---|
| **窗口大小** | 7 日？30 日？ |
| **居中还是滞后** | 居中的均值线在末端会缺失；滞后的末端完整但整体右移 |
| **最少样本数** | 样本不足时画不画？画了要说明 |
| **缺失处是否插值** | 插值就是在编造，要区分线型（见 `chart-correctness.md`） |

**默认值要写进图注** —— 否则"7 日均值"是一句没有定义的话。

## 两件常被忽略的小事

- **tooltip 会遮住数据**：它跟鼠标走时会盖住右上角的柱子。要么做窄、要么遮挡严重时让位、
  要么固定在图外（详情面板就是这个思路）。**选一个，别不管。**
- **不明文规定的阈值都是产品决策**："错误率 ≥ 3% 算异常"不是通用规则。
  把它**写在界面上**（图注、图例、详情面板），别让它藏在代码里。

## 图例切换的边界

全部序列都被隐藏时**自动恢复全部** —— 否则留下一张没有任何信息的空图，
而用户会以为它坏了。

## Y 轴要不要从 0 —— 两个方向都会错

**判据一句话**：**图形面积代表数量 → 从 0；图形只代表位置 → 不必从 0。**

| 图形 | 从 0？ | 为什么 |
|---|---|---|
| **柱状、面积** | **必须** | 面积代表数量。截断 Y 轴会**放大微小差异**，让不重要的差别看起来显著 |
| **折线、散点** | **不必** | 只表达位置与趋势。强行从 0 会把真实波动压成一条平线 |
| **折线 + 面积填充** | **必须** | 见下 —— 填了面积，它就开始表达数量了 |

### 折线延伸到 0（或 100%）的时机

即便折线"不必"从 0，下面两种情况该主动延伸：

- **数据本身就贴近 0** → 延伸到 0。此时读者不仅比较两点之间的垂直距离，
  还能比较它们**离零有多远**。
- **展示的是份额（百分比）且贴近 100%** → 延伸到 100%，同样的道理。
- **数据在中间区间波动**（如 60–100 的健康分）→ 保持自适应。

**判据**：**零（或 100%）本身是不是一个有意义的参照点？** 是，就画出来。

### ★ 给折线加面积填充，等于声明它是数量

这是上面那条规则最容易踩空的地方：折线可以从非 0，**是因为它只代表位置**。
一旦在它下面填了面积，读者看到的就变成"面积的大小"，**规则随之改变 —— 必须从 0**。

代价是真实的：日常值在 1% 左右、尖峰到 5% 的比率，从 0 起画会**被压成贴地的一条直线**。

**所以二选一，别两头占**：

- **想看清波动** → 去掉面积填充，让折线自适应域；
- **想表达"占了多少"** → 保留填充，从 0 起，接受波动被压缩。

## 对数轴：什么时候值得，什么时候是误导

**它解决的是跨数量级。** 数据从 1 跨到 1,000,000 时，线性轴会把小值那一段压成贴地的线。

**判据（经验）**：**最大值 / 最小值 ≳ 100 倍，且没有 0 或负值** → 可以考虑对数轴。
只要有一个 0，对数轴就画不出来（`log(0)` 无定义）；负值同理。

**但它有真实代价，必须一起处理**：

| 风险 | 处置 |
|---|---|
| 读者会**按线性读**，把倍数差看成差值 | **轴上写明"对数"**，刻度标 1 / 10 / 100 / 1000，而不是等距数字 |
| 等距的视觉间距 = **相同的倍数**，不是相同的量 | 网格线放在 10 的幂上，不要等分 |
| 零值、负值、缺失值在对数轴上**没有位置** | 要么剔除并**在图上说明**，要么就别用对数轴 |
| 小值的波动被视觉放大 | 若结论依赖"小值也重要"，那是**数据故事**的问题，不是轴的问题 |

**替代方案**：若只是想同时看清大小两端，**拆成两张图**（一张线性看整体、一张放大看小值）
通常比对数轴更不容易被误读 —— 与"不同量纲拆图"是同一条思路。

## 其他常见误导

| 不要 | 原因 |
|---|---|
| **双 Y 轴** | 暗示两个序列相关，而相关性是画出来的，不是数据里的。量纲不同的出路是**拆图**（见 `composite-charts.md`） |
| **3D** | 透视让读数失真，无任何信息增益 |
| **饼图超过 5 类** | 人眼分辨小扇区角度很差；改用柱状或堆叠条 |
| 面积图**叠加**比较不同序列 | 下面那条被遮住的部分无法读；要么分组，要么用折线 |
| 分类色超过 **6–8 种** | 颜色不再可区分；换分面或分组。（Wilke：定性配色在 **3–5 类**时最有效） |
| 只靠颜色区分序列 | 色觉差异者读不出；同时用线型、标记或直接标注 |
| ★ **曲线平滑**（spline / "自然"插值） | 曲线会在**两个数据点之间造出并不存在的高低起伏**。数据本身连续（温度）时平滑尚有理由；离散采样（月度销量）时，平滑就是在编故事。**直线最诚实** |

## 实线是采集，虚线是推测

一旦图上出现**估算、预测、插值补出的值**，就必须让读者分得清哪一段是实测的。
唯一可靠的做法是**线型**：

- **实线** = 真实采集到的数据
- **虚线** = 推算、预测、为连续性补出来的部分

**并在切换处标注**（"以下为预测"）。

**用颜色深浅区分是不够的**：那对色觉差异者无效，而且深浅在不同主题下会反过来。

同理，**如果数值在某点之后变成预测，要用高亮范围把那段区间框出来**，而不是只换一条线的颜色。
